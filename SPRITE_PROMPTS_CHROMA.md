# Sprite Regeneration Prompts — SOLID MAGENTA background (for clean keying)

Regenerate the SAME six characters, but on a **solid flat magenta background** instead of a checkerboard. Magenta (`#FF00FF`) never appears in dark-fantasy characters, so I can key it out perfectly — no more missing hood/edge chunks.

Paste **one at a time**. Same dark-fantasy style and 6×4 grid as before; only the background changed.

**Critical background rules (in every prompt):**
- Background = **solid flat pure magenta `#FF00FF`**, edge to edge. No gradient, no texture, no checkerboard, no vignette, **no drop shadow** under the character.
- **No magenta/pink anywhere on the character** — keep them dark-fantasy (charcoals, oxblood, tarnished gold, cold blue/green glows).

When done, drop them in the **RPG Painterly Images** folder and I'll key + install. Final files must be exactly **1264×848** (or any clean 6×4 grid), named `elder/brannock/tasha/edmund/wren/lyra.png`.

## Why magenta (honest)
- Your last sheets failed because the hood/cloak greys were the **exact same colour** as the checkerboard, so keying couldn't separate them.
- Magenta `#FF00FF` shares no colour with these characters → keying becomes a simple hue test, accurate to the pixel.
- If a generator refuses pure magenta or tints it, **bright chroma green is the only fallback — but NOT for `tasha`** (her green flask would vanish). For Tasha specifically, magenta only.
